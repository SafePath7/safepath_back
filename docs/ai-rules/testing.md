# 테스트와 완료 검증 규칙

## 테스트

- JUnit과 Mockito를 사용한다.
- 새 기능에는 관련 테스트를 작성하거나 기존 테스트를 보완한다.
- 오류 해결을 위해 기존 테스트를 삭제·무력화하지 않고, 테스트 전용 구현에 운영 코드가 의존하지 않게 한다.
- 가능한 범위에서 관련 테스트와 빌드를 실행한다. 실행하지 못했거나 실패했다면 원인과 해결 여부를 명확히 보고하며, 결과를 추측하지 않는다.

## 리팩터링과 완료 검증

- 리팩터링은 요청 범위와 실제 기능 변경에 필요한 수준으로 제한한다.
- 완료 전 요청 기능, 생성·수정 파일, 기존 기능 영향, API·DB 명세 유지, 중복·불필요 코드, 타인 코드 변경 여부를 확인한다.
- 완료 보고에는 구현 내용·변경 이유·검증 결과·수행하지 못한 검증과 사유를 포함한다.
